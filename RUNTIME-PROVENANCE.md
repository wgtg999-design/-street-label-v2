# Shared commerce runtime

JavaScript runtime adapted from wgtg999-design/- (commit b48a99134382394d6ade444d78ec70a889a7fd37). Existing authentication, owner checks, atomic stock/order transitions, uploads, and account UI are retained. No credentials or operating records were copied. Database initialization endpoints are deliberately omitted because this project connects to an existing database. V2 home settings use store_content key v2-home; existing main content is not rewritten.
